# CFOP Studio — reconstrução

Este projeto está sendo reconstruído do zero no GitHub, sem depender de acesso ao Replit ou ao ChatGPT para preservar os arquivos.

## Executar

Abra `v2/index.html` em um navegador moderno. O protótipo atual usa HTML, CSS e JavaScript sem instalação de dependências. Para hospedar no GitHub Pages, publique a pasta `v2` por um workflow ou mova a versão final para a raiz/docs após validação.

## Estado real da implementação

- Implementado: layout responsivo, navegação inicial, conteúdo introdutório de notação, trilha textual inicial de F2L intuitivo, cronômetro simples com inspeção configurável, histórico local e estatísticas básicas.
- Pendente: cubo 3D/2D matematicamente dinâmico, scrambles validados por motor de cubo, visualização do estado embaralhado, algoritmos dos PDFs, painel administrativo autenticado, revisão espaçada, PWA, sincronização entre dispositivos, +2 e regras oficiais completas, testes automatizados.
- A biblioteca de 41 F2L, 57 OLL e 21 PLL deve ser importada somente após conferência dos PDFs O CUBO / Adel Fonseca, distinguindo algoritmo de resolução e setup. Não inventar dados ausentes.

## Segurança

Nunca inserir credenciais, senhas, tokens ou chaves privadas no repositório. O painel administrativo futuro precisará de autenticação e autorização no servidor.
